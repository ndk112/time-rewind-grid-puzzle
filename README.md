# 时空轨迹 CHRONOS TRACE

双克隆影子与时间锚点协同解谜游戏。

## 核心机制

### 影子系统
- 按下 **E** 键进行时间回溯，产生一个克隆影子
- 影子会重复你上一次的完整路径
- **最多 2 个影子**，超出时最早的影子被覆盖

### 时间锚点
- 按下 **F** 键在当前格设立时间锚点
- 新锚点替换旧锚点，同时移除旧锚点绑定的所有影子
- 回溯后回到当前锚点位置（默认为起点）

### 撤销 / 重置
- **Q** 键撤销上一步
- **Delete** 键重置当前关卡

## 格子类型

| 符号 | 类型 | 说明 |
|------|------|------|
| `#` | 墙壁 | 不可通行 |
| `.` | 地板 | 可通行 |
| `S` | 起点 | 角色初始位置 |
| `~` | 出口 | 到达即过关 |
| `B1`~`B9` | 按钮 | 踩下翻转对应 ID 的门 |
| `D1`~`D9` | 门(默认关) | 按钮触发后开启 |
| `O1`~`O9` | 门(默认开) | 按钮触发后关闭 |
| `?` | 传送门 | 传送至另一个 `?` |

## 操作

| 按键 | 功能 |
|------|------|
| ↑↓←→ | 移动 |
| E | 时间回溯 |
| F | 设立锚点 |
| Q | 撤销 |
| Delete | 重置 |
| Space | 原地等待 |

## 游戏模式

- **闯关**：顺序通关，解锁下一关
- **选关**：自由选择已解锁关卡
- **创意**：编辑分享自定义地图

## 地图码

压缩编码，每格 1 字符，行间用 `x` 分隔：
`#`→0 `.`→1 `S`→2 `~`→3 `?`→4
`B1`~`B9`→5~d `D1`~`D9`→e~m `O1`~`O9`→n~v
